# GR Sort — сортировщик файлов

**GR Sort** — это десктопное приложение на C# с графическим интерфейсом (Windows Forms), предназначенное для быстрой и удобной сортировки файлов в выбранной пользователем папке. Программа автоматически раскладывает файлы по подпапкам в зависимости от их расширения, типа или других критериев (настраивается). Главная фишка — возможность отменить сортировку, если вы передумали.

## Возможности

- Выбор папки через стандартный диалог.
- Сортировка файлов по расширениям (каждое расширение -> своя папка).
- Индикация прогресса во время выполнения.
- Кнопка **Отменить** — прерывает сортировку в любой момент.
- Простой и интуитивно понятный интерфейс.
- Не требует установки — достаточно запустить `.exe`-файл.
